## Zweck der Anwendung

HermesAgent ist ein privater, persönlicher Assistent. Er wird ausschließlich vom Betreiber für sein eigenes Google-Konto genutzt und ist nicht für Dritte bestimmt.

## Welche Daten verarbeitet werden

Nach der Anmeldung mit Google (OAuth) greift HermesAgent nur auf die Daten zu, für die bei der Anmeldung ausdrücklich eine Freigabe erteilt wurde, zum Beispiel E-Mails, Kalendereinträge oder Kontaktdaten des eigenen Kontos. Die Daten werden nur verarbeitet, um die vom Betreiber angeforderten Aufgaben auszuführen.

## Weitergabe und Speicherung

Daten aus Google-Konten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben. Zugriffstoken werden nur so lange gespeichert, wie es für den Betrieb nötig ist. Der Zugriff kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.

## Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die HermesAgent von Google-APIs erhält, entspricht der [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
